# Rock-paper-scissors

Description:
A fun, interactive Rock-Paper-Scissors game with score tracking and a winner popup. Built using C++ and C++ Builder for a simple GUI-based experience.

🔧 Tech Stack:

    >  C++
    >  C++ Builder (RAD Studio)

💡 Features:

    >  Game logic with three options (Rock, Paper, Scissors)
    >  Scoreboard tracking
    >  Restart button
    >  Winner announcement popup
